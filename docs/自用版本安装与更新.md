# SideBar 自用版本：安装与更新

这个仓库（`Dongmayyys/SideBar`）是自用维护的版本，不再跟随上游 `oidd/SideBar` 发布，也去掉了上游的更新检查，避免被提示装回上游版本。功能说明见 `多窗口收纳标签交互规格.md`。

## 在一台新 Mac 上安装

1. 安装命令行开发工具（已装过会提示已安装）：

   ```bash
   xcode-select --install
   ```

2. 拉取代码：

   ```bash
   git clone https://github.com/Dongmayyys/SideBar.git ~/Developer/SideBar
   ```

3. 建签名证书（推荐，一次性）。不建也能用，但以后每次更新都要重新授权辅助功能。
   1. 打开“钥匙串访问”，菜单 **钥匙串访问 → 证书助理 → 创建证书…**
   2. 名称填 `SideBar Local Signing`（一字不差），身份类型选“自签名根证书”，证书类型选“代码签名”，勾选“让我覆盖默认值”。
   3. 有效期改为 `3650` 天，其余保持默认，钥匙串选“登录”，创建。
   4. 不需要把它设为“始终信任”。

4. 构建并安装：

   ```bash
   ~/Developer/SideBar/Scripts/install-app.sh
   ```

   第一次签名时如果弹窗询问 codesign 能否使用钥匙串中的密钥，点“始终允许”。

5. 授权辅助功能：**系统设置 → 隐私与安全性 → 辅助功能**，打开 SideBar 的开关（列表里没有就点“+”从“应用程序”添加）。授权后退出 SideBar 再打开一次。


## 默认设置

新装后不需要再调这些，默认值已经按自用习惯设好：

| 设置 | 默认值 |
|---|---|
| 收纳快捷键 | ⌃⌥⌘S |
| 回到主界面 | ⌃⌥⌘H |
| 防误触缓冲（悬停延时） | 100 毫秒 |
| 水平 / 垂直容差 | 60 / 60 |

## 更新

```bash
cd ~/Developer/SideBar && git pull && Scripts/install-app.sh
```

安装脚本会先正常退出 SideBar（收纳的窗口放回原位），替换后重新打开，收纳自动恢复。安装不会改动设置。

要回到旧版本，切到对应提交再装一次即可，例如：

```bash
git checkout <提交号> && Scripts/install-app.sh && git checkout main
```

## 构建说明

- `Scripts/build-app.sh` 只生成 `build/SideBar.app`，不安装。
- 签名：优先用钥匙串里的 `SideBar Local Signing` 证书，找不到时退回临时签名。可用环境变量 `SIDEBAR_SIGN_IDENTITY` 换用别的证书名。
- SDK：默认使用系统当前的 macOS SDK；如果编译报工具链与 SDK 不匹配，脚本会自动改用命令行工具里其他版本的 SDK 重试。也可以用 `SDKROOT` 手动指定。
- 诊断日志：`~/Library/Logs/SideBar/stash.log`，记录快捷键收纳窗口的展开、收回和激活判断。
